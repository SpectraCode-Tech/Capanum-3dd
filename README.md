# Capanum site (React + Vite + React Three Fiber + GSAP + Lenis)

Run locally:  npm install && npm run dev
Build:        npm run build   (output in dist/)
Deploy:       upload dist/. It is a single-page app, so the host must send every path to index.html
              (dist/_redirects covers Netlify, dist/.htaccess covers cPanel/Apache).

Before launch
- All copy, contacts, RC 9240215, testimonials and the 7 services come from the client's current site (src/data.json, generated by gen_data.py).
- WhatsApp buttons use +234 809 877 1010 (first number on the current site). Change WHATSAPP in gen_data.py if a different number is used.
- Lagos branch has no address on the current site, so none is shown.
- Brand colours from the logo: crimson #9e333b, plum #782f5c, red #e5262b (src/index.css).

Prerendering (SEO)
dist/ already contains prerendered HTML for all 13 routes plus sitemap.xml. After any content change:
  npm run build && python3 scripts/prerender.py   (pip install playwright && playwright install chromium)
Then submit sitemap.xml in Google Search Console and create a Google Business Profile for the Abuja office.
